# dotfiles

### Installation

```sh
➜ git clone git@github.com:mrfishball/dotfiles.git ~/dotfiles
➜ cd ~/dotfiles
➜ ./install.sh          # full macOS setup, then symlinks
➜ ./install.sh link     # symlinks only
```

Existing files are backed up to `~/.dotfiles_backup/<timestamp>/` before being replaced.
